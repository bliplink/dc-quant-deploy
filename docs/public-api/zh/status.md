# 发布状态

Trader / Broker API 当前为**开发者预览版**，环境仅使用模拟资金；不是 External GA 服务，也没有生产 SLA。文档发布不代表交易核心、高可用和外部接入全部达到公开商用门槛。

当前 OpenAPI YAML 覆盖 28 个公开方法及其请求 schema，但在正式开放前仍需完成并验证：长时间交易稳定性和异常切换目标、更高负载验收、外部 WebSocket wire/心跳契约、可安装并完成端到端验收的 Trader/Broker SDK、资金操作幂等与结果不明时的恢复，以及独立的 Sandbox 凭据/重置流程。英文字段级参考也尚未全部完成。

请只使用可丢弃的 Demo 账户，不接入真实资金。订单或资金写入超时后，先根据原有业务标识查询结果，不能直接盲目重试。
