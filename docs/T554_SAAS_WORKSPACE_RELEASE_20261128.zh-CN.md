### 运行数据

验收时十个 Robot 合计报告 400 笔挂单。按点价账户、成交类型和 taker 侧筛选，最近一分钟十户均有成交，共 268 笔。Order 和 Trade 各 256 个分区全部为 STRICT_QUORUM、READY，各自 A、B 承担 128 个主分区。以上为运行快照。

交互测试使用模拟账户及资金。四笔市价单最终平仓后，测试账户余额为 99.66875056；出金 1 后余额为 98.66875056。测试留下真实模拟流水，目录显示名统一为 BTC Demo 01 至 10。

### 性能与对外边界

同一台 Mac 经公网，用独立 Chrome 会话从导航开始计到首条可点击的市场行出现，每个尺寸每轮三次。桌面中位数从 5.89 秒降至 3.32 秒，手机从 4.06 秒降至 2.85 秒。新路径在初始 HTML 内提供首屏目录，不再串行等待浏览器单独往返目录接口。改造后桌面三次为 3.316、4.115、2.720 秒，手机为 2.607、3.440、2.846 秒。建议目标 P95 ≤ 2 秒尚未验收通过。云边缘响应标为 DYNAMIC，样本包含连接等待，需要目标地区独立采样进一步定位首字节耗时。

本轮覆盖的是公开模拟演示的正常用户路径。跨地区延迟、严格及异步模式持续 1,000 笔/秒且交易端到端 P99 ≤ 20 毫秒、繁忙租户对其他租户的影响、长时间故障恢复均需各自的验收记录。全角色 API 权限矩阵、跨设备找回申请以及试用到期后的用户流程也需专项验证。
