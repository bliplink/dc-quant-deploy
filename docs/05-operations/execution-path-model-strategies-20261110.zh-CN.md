# 执行路径标签模型：本地源码补库存批次

## 为什么是新假设

此前冻结模型预测未来固定时间的收盘收益，而实际策略是次根限价成交、动态止损止盈和移动止损。这个批次直接用可成交的路径收益构造历史监督标签，不是修改失败版本的止损参数或对同一前瞻调参。正式财务资格没有变化。

所有训练仍只读冻结READY中2024-12-15之前的10品种OHLCV；即使实际标签提前结束，整个96根潜在观察区间也必须严格早于验证起点。训练从2024-08-15开始，每16根取样；不同标签可能重叠，明确不声称独立样本、显著性或收益保证。

多头6,841个、空头6,848个已观察标签；未成交和96根内未结束的路径被排除，不伪造为零收益。4组特征分别是动量、相对价值、波动、UTC时段/价格成交量结构；每组岭回归及浅层提升回归各一类，每类含独立训练的多空模型，共16个数值模型、8个Java策略类、16个候选方向，不等于16条实盘策略。

固定参数沿用alpha=200、24棵树、深度2、最小叶100、学习率0.05、种子20261110。原12个因果特征外增加UTC日/周正余弦、32根方向效率和16根方向成交量占比。只需200根已完成K线。Java直接嵌入常量，无模型API或Python依赖。

## 执行标签边界

训练标签复制现有引擎的事件顺序：信号后仅下一根有效限价；成交根不执行持仓风控；之后同根止损/止盈冲突时先止损；已有风险检查完成后才按收盘价更新移动止损，下根生效。固定1.5/3 ATR止损止盈、0.5%首阶和0.2%步阶不随回测成绩调整。

这仍是训练代理，不宣称替代正式引擎：有96根删失窗口，没有场景强平及后续信号干扰；成本按2/5bps费用及4/5bps压力的进出名义金额近似，与正式引擎费用记账存在细小基准差异。删失样本的选择也可能造成偏差。因此上线判断只接受原SIMSvr的完整执行、场景、成本和前瞻资格，不使用训练误差作凭据。

入场规则在财务检查前固定：模型预测的扣费净空间须大于8bps，且比反方向模型的净空间高8bps；保留既有目标空间至少48bps的限制。不同特征组/模型算法是否构成独立实盘逻辑，仍需按最终候选审查，不能仅凭类名计数。
