# 入场ATR缩放退出：财务检查前冻结协议

## 新假设及非结论

前面各批均未形成新增发布。代码复核确认研究模拟`applyTrailingProtection`及源码导出模板均对全部策略固定0.5%启动、0.2%步进。这是原先统一退出设计，不是已证实的服务故障；不同价格波动尺度下，固定百分比保护距离可能与ATR止损止盈不成比例。本批检验不同的、可在现有Signal字段中表达的退出假设，不承诺因此盈利。

只对新候选采用以下固定规则，不改变原策略或生产运行时：沿用10种原价格结构入场、1.5 ATR止损、3 ATR止盈；移动保护首阶为入场2 ATR并遵守现有EMS的0.5%下限，步阶0.5 ATR。未受下限约束时，首阶触发后保护1.5 ATR，即一个原始风险单位；受下限约束时按“实际首阶-步阶”保护。按信号时ATR/入场价格转成百分比，在该持仓内冻结，不用后来ATR重算。

在任何本批金融验证之前核对生产EMS，发现0或空保护字段会转用用户默认值，不能表示禁用。新策略必须显式提供4个正百分比：保底触发为“实际首阶+步阶”、保底保护为“实际首阶-步阶”。按现有分支顺序，该保底不会早于首阶移动规则触发，也不会因0值落入Telegram默认策略。0值或部分配置在新退出合同中直接拒绝。

这改变新策略的实际退出管理，不改变手续费、执行压力、最低交易数、PF、回撤、OOS、留出、场景、前瞻贡献或替换基线门槛。更宽的保护也可能增加亏损，不能仅展示有利路径。旧固定退出和新ATR退出的同一基础入场机制不当成两条独立逻辑凑数量。
